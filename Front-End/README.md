# Playlog — Front-End

Interface do Playlog, feita com React e Vite (JavaScript).

## Requisitos

- Node.js 24 (definido no `mise.toml` da raiz do projeto)

## Comandos

```bash
npm install      # instala as dependências
npm run dev      # servidor de desenvolvimento em http://localhost:5173
npm run build    # gera a versão de produção em dist/
npm run lint     # verifica o código com o ESLint
```

## Estilos

As cores, espaçamentos e transições da identidade visual ficam como variáveis CSS em `src/index.css`.
